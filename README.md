## 📌 Sobre o desafio

O **100 Days of Code** é um desafio pessoal criado para desenvolver consistência na programação através da prática diária.

Durante os 100 dias, meu objetivo é estudar, desenvolver projetos, aprender novas tecnologias e registrar minha evolução aqui no GitHub.

> 💡 **A ideia não é apenas completar 100 dias, mas evoluir um pouco a cada dia.**

</details>

<details>
<summary>📁 Dia 04 — Sistema de controle de estoque</summary>

### Objetivo

Criar um sistema para cadastro e gerenciamento de produtos, evoluindo o projeto para trabalhar com **persistência de dados**.

### Funcionalidades

* Cadastro de produtos
* Listagem de produtos
* Busca de produtos
* Exclusão de produtos
* Salvamento em arquivo `.txt`
* Leitura dos dados ao iniciar o programa

### Aprendizados

* Manipulação de arquivos
* `open()`
* Leitura e escrita em arquivos
* `os.path.exists()`
* `.split()`
* Persistência de dados
* Estruturação de informações

</details>
